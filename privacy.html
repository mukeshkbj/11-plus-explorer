11+ Explorer: Privacy policy

Last updated: 23 November 2026

In short: 11+ Explorer has no accounts of its own, no adverts, no analytics and no tracking. Progress is saved on your device. Nothing leaves the device unless a parent chooses to turn on one of the optional features described below.

Who we are

11+ Explorer is a free, open-source practice app for the 11+ exam, made by a parent for his children. The source code is public at github.com/mukeshkbj/11-plus-explorer.

What is stored, and where

  • Progress (answers, scores, stars, badges, history, settings, each child's first name and chosen animal) is stored only on the device, inside the app or browser.
  • We (the makers) never receive this information. There is no server of ours that collects it.
  • A parent can save a backup file from Settings. That file stays wherever the parent saves it.

Optional features a parent can turn on

These are off until a parent sets them up in the PIN-protected parent area.

  • AI-made questions. If a parent adds their own API key for Anthropic (Claude) or OpenAI, the app sends requests to that company to write practice questions. A request contains the subject, the topic and the level only. It does not include the child's name or progress. The key is stored only on the device and is never included in backup files. That company's own privacy policy applies to these requests.
  • Sync between devices. If a parent connects their own Google Firebase project and signs in, each child's progress (including their first name) is copied to that parent's own Firebase account, so it can appear on their other devices. The data is under the parent's control in their own Google account. Google's privacy policy applies to it.
  • Reporting a problem with a question. Reports are saved on the device. A parent can choose to send one to us by opening a pre-filled public report on GitHub. It contains the question and the reason, not the child's name.

Children's privacy

The app is designed for children aged 9 to 11 and for their parents. It does not ask children for any personal information other than a first name, which stays on the device. Optional features that send information off the device can only be turned on by a parent in the PIN-protected parent area.

Deleting information

Use Settings → "Clear all progress" to delete a child's progress, or remove a child in Settings. Uninstalling the app (or clearing the browser's site data) deletes everything stored on the device. If sync was turned on, the copy in the parent's Firebase project can be deleted in the Firebase console.

Changes

If this policy changes, the new version will be published on this page with a new date.

Contact

Questions about privacy: please open an issue at github.com/mukeshkbj/11-plus-explorer/issues.
